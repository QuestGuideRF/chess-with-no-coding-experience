# Chess with No Coding Experience

Локальная шахматная игра на Python с графическим интерфейсом на базе `turtle`. Проект запускает полноценную шахматную доску, позволяет двум игрокам ходить по очереди мышью и реализует базовую игровую логику без внешних зависимостей.

## ✨ Особенности

- Графическая шахматная доска, отрисованная средствами стандартной библиотеки Python.
- Управление кликами мыши: выбор фигуры и хода осуществляется прямо на поле.
- Поддержка основных типов фигур и их правил перемещения.
- Поддержка взятия фигур.
- Реализована рокировка на королевский и ферзевый фланг.
- Реализовано взятие на проходе (`en passant`).
- Подсветка выбранной фигуры.
- Визуальная индикация шаха для белого и чёрного короля.
- Автоматический переворот доски после каждого хода для смены стороны.

## 🚀 Быстрый старт

### Требования

- Python 3.x
- Доступный графический интерфейс ОС, так как используется модуль `turtle`

Из корня проекта выполните:

```powershell
python "chess with no coding experience.py"
```


После запуска откроется окно с шахматной доской.

### Ключевые части кода

- `notation` хранит координаты клеток доски в шахматной нотации (`a1`-`h8`).
- `piecePositions` хранит текущее расположение фигур по клеткам.
- `pieces` описывает тип фигуры, её позицию, цвет и служебные флаги состояния.
- `selectPiece()` обрабатывает выбор фигуры.
- `checkSquare()` проверяет легальность хода для выбранной фигуры.
- `selectSquare()` выполняет ход, взятие, рокировку, взятие на проходе и пересчёт состояния игры.
- `flip()` переворачивает доску после завершения хода.

## 🛠 Использование

1. Запустите приложение.
2. Кликните по фигуре текущего игрока.
3. Кликните по целевой клетке или по фигуре соперника для взятия.
4. После успешного хода доска автоматически перевернётся, и ход перейдёт другой стороне.

### Что поддерживается

- Обычные ходы фигур.
- Взятие фигур соперника.
- Рокировка.
- Взятие на проходе.
- Проверка атаки на клетку короля и визуальное уведомление о шахе.

### Что важно учитывать

- Игра рассчитана на двух игроков за одним компьютером.
- В проекте не реализованы шах и мат как завершение партии.
- В проекте нет превращения пешки.
- В проекте нет меню, настроек, сохранений и режима игры против компьютера.
- Зависимости не требуются: используются только `turtle` и `time` из стандартной библиотеки Python.

- Заголовок окна задаётся как `chess`.
